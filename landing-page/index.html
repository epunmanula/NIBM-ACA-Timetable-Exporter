The Problem & The Solution

Built by Students, Designed for Speed

Why manual timetable copying is frustrating, and how we solved it completely.

Without This Extension

  • ✕ Hidden Modal Data: Lecturer names, venues, and lecture times only show when you click each card individually.
  • ✕ Hours of Tedious Clicking: A typical semester has 80–190 lectures across 4–6 months. Clicking all of them takes forever.
  • ✕ Multi-Month Mess: Navigating month-by-month loses your place and creates fragmented schedules.
  • ✕ Excel Formatting Glitches: Copy-pasting text from the browser corrupts Sinhala Unicode characters and breaks columns.

With NIBM ACA Exporter

  • ✓ Automated Headless Clicker: Dispatches native pointer events to open every detail modal, extract data, and close it in milliseconds.
  • ✓ 1-Click Multi-Month Scan: Advances through all semester months sequentially and compiles all events automatically.
  • ✓ Single Chronological CSV: Pre-sorts every lecture by date ascending, ready to open in Microsoft Excel, Google Sheets, or Notion.
  • ✓ RFC 4180 & UTF-8 BOM: Perfect character rendering for Sinhala (සිංහල) and English without broken symbols.

Core Capabilities

Everything You Need to Manage Your Semester

Engineered specifically for the quirks of Next.js, SPA hydration, and Radix UI dialogs.

Automated Modal Clicker

Simulates native mouse & pointer event sequences (`pointerdown`, `click`) to trigger React event listeners, open the detail dialog, scrape rich data, and close it automatically.

Multi-Month Auto-Scan

Click "Scan All Months" to automatically advance through consecutive semester months with settling delays, accumulating the entire semester into a single dataset.

RFC 4180 Single CSV

Generates strict RFC 4180 CSV files with UTF-8 BOM (`\uFEFF`) and CRLF line endings. Opens seamlessly in Microsoft Excel with perfect Sinhala and English character fidelity.

Zero-Knowledge Security

Operates 100% locally in your browser. Never reads or stores passwords, OTPs, session cookies, or authorization tokens. Zero external network calls.

Smart Legend Exclusion

Strictly distinguishes between real calendar day cards and footer legend reference badges (such as `SM Seminar` or `WS Workshop`), eliminating ghost records.

Real-Time Search & Filters

Filter by lecture type (`LP`, `LB`, `EX`), date ranges (`From` / `To`), or search by lecturer or hall name with instant table updates and auto-filter reset protection.

Behind the Scenes

How the Scraper Engine Works

A deep dive into the 4 architectural phases that make seamless scraping possible.

01

Dynamic SPA Context & Month Sync

When you navigate across months in ACA, Next.js updates the calendar heading (e.g. December 2026) and query parameters. The engine continuously reads the heading and synchronizes the active year and month, automatically correcting ACA's 0-indexed month parameter bug (where month 11 represents December).

02

Strict Calendar Cell Date Binding

Instead of guessing dates from isolated text snippets, each card is anchored directly to its parent day cell (1 to 31) in the calendar grid. This guarantees that card dates (card.cellDate) are 100% accurate and never contaminated by previous months.

03

Headless Modal Crawling & Dismissal

The scraper iterates over all cards, triggers the detail dialog using synthetic pointer sequences, extracts the lecturer name, hall venue, exact time span, and learning mode, and safely dismisses the modal via Escape key and close buttons before advancing.

04

Chronological Sort & Single CSV Assembly

All multi-month events are deduplicated while preserving multiple lectures scheduled on the same date (e.g. morning + afternoon slots). The entire collection is sorted strictly by date and start time, and exported as a single RFC 4180 CSV file with UTF-8 BOM encoding.

Quick Setup

How to Install in Google Chrome

Get up and running in under 60 seconds with 3 simple steps.

Step 1

Download or Build

Clone the repository and build the production bundle:

git clone https://github.com/epunmanula/NIBM-ACA-Timetable-Exporter.git
cd NIBM-ACA-Timetable-Exporter
npm install
npm run build

This creates the dist/ directory ready to load into Chrome.

Step 2

Enable Developer Mode

Open Google Chrome and navigate to the extensions management page:

chrome://extensions

Switch on the Developer mode toggle located in the top-right corner.

Step 3

Load Unpacked

Click the "Load unpacked" button in the top-left toolbar and select the dist/ folder:

path\to\NIBM-ACA-Timetable-Exporter\dist

The extension is now installed! Pin it to your Chrome toolbar for easy 1-click access.
